## 摘要

可提交模型是一条 C-free 骨架：只吃元数据，不读该样本的实测对照，
`metadata → 低秩 K₀=16 → 全维 5,243 解码`。官方四类 val 六项加权总分 **0.4694**，
高于全部需读对照的 oracle 诊断基线（最高 0.3843）。

本轮做的主要不是提分，是**把结论钉死**：

1. 修掉两处训练边界违规，并把「合规」做成任何人能跑的检验，而不是一句声明；
2. 把化合物结构表示的否定结论重做在合法样本上，并补第二个阳性对照堵住
   「你的模块是不是被正则压死了」这一问；
3. 按预注册判据做完并**否定**了外部菌株基因组这条 S2 提分路线；
4. 首次做 test 真值自评，发现测试集的对照结构与训练集**根本不同**——
   这一条比总分更影响对成绩的解读。

## 一、任务与评分口径

### 1.1 任务

给定酿酒酵母在特定菌株、化合物、培养基、温度、时间与测量上下文下的扰动蛋白质组，
预测独立测试样本的完整 5,243 维 log2 蛋白丰度向量。

四类外推场景：S1 未见化合物（`chem_only`）· S2 未见菌株（`strain_only`）·
S3 双重未知（`both`）· 时间插值（`time`）。

### 1.2 评分器复刻与四处官方未定义项

官方六项指标有多处未在手册中定义，任选其一都会系统性改变模型排名。
我们把它们全部做成参数而非写死，并配 61 项单元测试（`scripts/scorer/test_metrics.py`）。
本方案采用的取值：

| 未定义项 | 我方取值 | 为什么这么选 |
|---|---|---|
| 多个合法对照如何合并 | 逐蛋白中位数 | 92.9% 的处理样本匹配到多个对照（中位 2 个），均值对离群对照不稳 |
| 常数向量导致 PCC 未定义 | 记 NaN | 见下条，与轴规则配合 |
| 整条聚合轴全未定义 | 记 0 后与另一轴等权平均 | 记「踢出」会奖励「让整条轴未定义」的退化模型：全局均值谱在每个蛋白上都是常数，蛋白轴全未定义，踢出等于白送一档 |
| 某个评分模块整体未定义 | 按 0 计入，分母保持满权重 | 同理，否则 Δ≡0 这类基线靠未定义指标虚高 |
| 指标 5 的构成 | FC 与绝对保真度都算 | 手册原文两个分量都提了，只算 FC 会漏掉一半 |

开发过程中这套测试捕获了三类会改变排名的实现缺陷，其中两类值得单列：

- **未定义轴被静默踢出**：B0 的 `abs_pcc` 曾算出 0.9535，现行 0.4768。差了一倍。
- **float32 舍入噪声被当真信号**：B2 的上下文残差理论恒为 0，修复前算出 0.0011、修复后 0.0000。
  根因是常数判据用了 `1e-12` 这种绝对阈值，而预测按 float32 落盘时
  `(C + μ) − C` 会残留约 `2.4e-6` 的舍入噪声。现按 float32 在 log2 丰度量级上的
  表示精度取阈值 `1e-5`，Δ 的真实尺度 sd ≈ 0.4 比它大四个数量级，不会误伤。

## 二、数据实况

### 2.1 规模与缺失

| 项 | 值 |
|---|---|
| train_val 样本 / test 样本 | 8,958 / 4,454 |
| 蛋白维度 | 5,243 |
| 处理样本（非对照非质控） | 7,884 |
| 丰度缺失率 | 27.35% |
| 处理样本的 Δ 缺失率 | 28.93% |
| 全缺失蛋白列 | 丰度侧 186 · Δ 侧 213 |

缺失**不是随机的**：蛋白中位丰度与其缺失率的 Spearman 相关 **−0.859**；
最低丰度十分位的缺失率 **77.4%**，最高十分位 **1.6%**。
这是典型的检测限截断（MNAR）。全流程不做任何填补——缺失位置不进损失，
不当作已知值参与拟合。

### 2.2 对照匹配

按手册规定的 7 项键（来源/菌株/培养基/温度/时间/仪器/板号，不含孔位）匹配：

- train_val 侧 **0 匹配率 0.0%**，多匹配比例 92.9%（中位 2 个对照）
- test 侧的情况完全不同，见第六节——那是本轮最重要的一个发现

### 2.3 生物与技术因素高度混杂

板号与培养基 / 温度 / 时间的 Cramér's V 全部是 **0.992**。
生物 + 技术的联合设计矩阵 296 列、秩 267，**亏秩 29**。

直接后果：**板号不能进模型**。加板号等于把这三个生物变量的身份背下来，
换一批新板就失效。这不是保守，是亏秩 29 决定的。

### 2.4 单样本 Δ 的可靠性只有 0.115

跨板 / 跨来源的复制对共 4,384 对，逐样本相关：

| 空间 | ρ |
|---|---|
| 绝对 log2 丰度 | **0.921** |
| Δ_true（匹配 FC） | **0.115** |
| Δ − μ_ctx | 0.157 |
| Δ − μ_drug | 0.059 |

⚠ 这个 ρ 是**操作性一致性**，不要解释成「信号只占 11.5%」——
它同时包含了对照匹配引入的方差。

但方向是清楚的：**绝对丰度可靠，单样本响应几乎不可靠**。
这一条直接决定了架构优先级——把力气放在绝对基线上，而不是给每个化合物学一条响应谱。

## 三、共享参照效应：一个必须先说清楚的评分陷阱

评分定义里 `Δ_pred = ŷ − y_control` 与 `Δ_true = y − y_control` **减去同一条实测对照**。
于是一个对药物一无所知的模型，也能在扰动指标上拿到不低的分。

拿全局均值谱（B0，完全不含药物信息）做三条件对照实验：

| 条件 | 样本轴 PCC | 蛋白轴 PCC |
|---|---|---|
| 正确匹配（官方口径） | 0.1845 | 0.1898 |
| 错配到**同条件**的别的样本 | 0.0825 | 0.0855 |
| 全局错配到随机样本 | 0.0076 | 0.0038 |

一个零知识模型在指标 2 上拿到 0.18，而它对药物一无所知。

⚠ 三条件之差**不能**拆成可相加的信号份额——相关系数不具可加性。
这组数只说明一件事：**共享参照抬高了零知识基线，指标 2 不可单独作模型选择依据**。

可复现实验：`scripts/audit/shared_reference_probe.py`。

## 四、模型与结果

### 4.1 为什么是 C-free

此前的 B1/B2/B3/B4、低秩响应、α 收缩**全部**是 `ŷ = C + Δ̂` 形态，
推断时需要读该样本自己的实测对照。

原来我方给的理由是保守假设（测试集真值被隔离）。
手册 2026-08 修订版推翻了那个前提——测试真值随包发布，供自评参考。
**但同一份手册第 17 页写着，最终评审用组委会另备的一组独立内部评测集，不随赛题发放。**

于是理由反而更硬：**任何在推断时需要读该样本对照的模型，在那组我们永远拿不到的
数据上根本跑不起来。** 这不再是保守假设，是可用性问题。

模型里有一道守卫强制这件事（`assert_c_free`）：判据是「预测与该样本自己的对照的相关，
不应高于它与**在模型所用条件变量上完全相同**的另一个样本的对照的相关」。
守卫自己先过阳性对照——拿一个已知偷用了 C 的模型（`ŷ = C`）去测，必须被拦下。
抓不到已知泄漏的守卫，没有资格给别的模型背书。

### 4.2 成绩

官方四类 val，六项加权总分：

| 组 | 模型 | total |
|---|---|---|
| 需读对照（oracle 诊断，**不可提交**） | B1 预测=匹配对照 | 0.2836 |
| | B3 化学近邻响应 | 0.2898 |
| | B2g 总体平均响应 | 0.3087 |
| | B2 上下文均值响应 | 0.3111 |
| | B3o 神谕近邻（响应空间上限） | 0.3220 |
| | B4 ridge 响应 | 0.3381 |
| | 对照收缩 α=0.15 | **0.3843** |
| C-free（**可提交**） | 全局均值谱 | 0.2587 |
| | 逐蛋白 ridge（满秩） | 0.4406 |
| | **低秩 K₀=16 + ridge** | **0.4694** |

**不读对照的可提交模型，反而高于全部需读对照的诊断基线。**

⚠ 两组的推断前提不同，不是同一张名次表。上组只用来定水位。

### 4.3 低秩这一步值多少，以及怎么确认它不是噪声

从满秩逐蛋白 ridge 换成 K₀=16 低秩：总分 0.4406 → 0.4694。

**按化合物分组的配对 bootstrap**（60 次，46 个分组）：
差值均值 **+0.0282**，95% 区间 **[+0.0211, +0.0346]**，排除 0，低秩更优的比例 100%。

⚠ 判据必须看**配对差值**的区间，不能比较两条边际区间是否重叠——
两个模型跑在同一批数据与同一批重抽样上，估计高度相关。

⚠ 按行 bootstrap 会严重低估不确定性（同一化合物有上百个相关样本），故按整组重抽样。

### 4.4 K₀ 必须用端到端口径选

| K₀ | total |
|---|---|
| 8 | 0.4505 |
| **16** | **0.4694** |
| 32 | 0.4691 |
| 96（重建口径选出的） | 0.4674 |
| 满秩 | 0.4406 |

此前用「观察留出样本一半蛋白、重建另一半」选 K，选出 96。那是**插补**口径——
真实预测时看不到留出样本的任何蛋白值。两个口径选出的 K 不同，
本身就说明重建 RMSE 不能用来定部署用的秩。

### 4.5 分场景

| 场景 | n | abs_r2 | fc_pcc |
|---|---|---|---|
| `val_chem_only`（S1 未见化合物） | 1,065 | 0.8525 | 0.3505 |
| `val_strain_only`（S2 未见菌株） | 1,547 | 0.7233 | 0.3265 |
| `val_both`（S3 双重未知） | 269 | 0.7631 | 0.3035 |
| `val_time`（时间插值） | 157 | 0.8284 | 0.3506 |

S2 是最弱的一格，而它在测试集里占的分量最重——这是下一节与第六节要处理的问题。

## 五、两条被否定的路线

负结果同样是结果。两条路线都**先写判据、再跑实验**，不是跑完再找说法。

### 5.1 化合物结构表示：拿不到可验证的预测增益

严格 nested LOCO，宇宙收进 `split_final == 'train'` 的 **37 个**合法训练化合物，
8 折整化合物留出，化合物等权，指纹 bit 过滤与描述符标准化只在外层训练折内拟合，
λ 由内层二次留出选，每折的设计矩阵词表与时间标准化参数只由该折训练行冻结。

| 配置 | fc_pcc | 相对仅上下文 |
|---|---|---|
| 仅上下文 b̂（无化合物信息） | 0.3521 | — |
| + ECFP 结构表示 | 0.3526 | **+0.0004** |
| shuffled-label 对照（5 次） | — | −0.0000 ~ **+0.0007** |
| [阳性对照 2] 神谕特征**走同一模块** | 0.3739 | **+0.0217** |
| [阳性对照 1] 神谕挑近邻照搬残差 | 0.3822 | **+0.0300** |
| [天花板] 神谕用留出化合物自己的平均残差 | 0.4195 | **+0.0674** |

真增益 +0.0004 落在打乱对照的带子里（最大 +0.0007），与随机指派分不开。
按预注册标准，结构项权重设为 0。

**这个否定为什么有效力——靠的是两个分工不同的阳性对照。**

- 对照 1（+0.0300）**绕过**岭回归模块，证明「b̂ + 化合物残差」这个架构能给分、
  评分口径也认。
- 对照 2（+0.0217）**不绕过**，走同一条 `fit_response`、同一套内层 λ 选择，
  只是把特征换成已知有信息的那种。它堵的是最容易问倒人的一句：
  「你的模块是不是被内层 λ 压成 0 了？那 ECFP 拿不到增益是必然的，
  你这检验对『结构表示行不行』根本没有效力。」
  同一条路径换个特征就拿得到 +0.0217，模块显然没被压死。

官方 `val_chem_only` 一次性确认（6 个化合物，只看一眼、不参与选参）：
总分差 +0.0002，方向一致。

⚠ **可判定的只有**：当前的 2D 指纹与最近邻基线，不足以定位响应相似的化合物。
**不可升级成**「分子结构预测不了响应」——失效原因至少还有：只有 37 个合法训练化合物、
化学空间稀疏、只用 2D 指纹、作用浓度、摄取与外排、代谢、酵母中不存在的靶点、多靶点。

**这条路线的天花板**：用留出化合物自己的平均残差当 Δ̂（完全作弊），fc_pcc 增益 +0.0674，
按指标 2 的 25% 权重折成总分约 +0.0168。任何「给每个化合物预测一条响应谱」的模型
都不可能超过 fc_pcc 上的这个数。⚠ 该折算假设其余五项不受影响，未经检验。

对比：绝对骨架改一步（满秩 → 低秩）就是 +0.0287，且区间排除 0。
**架构优先级由此确定：力气放在绝对基线，不放在化合物特异模块。**

### 5.2 外部菌株基因组：按预注册判据不保留

手册修订对照表允许外部公开资源用于实体特征构建。S2 是最弱的一格，
测试集里未见菌株占 50.1%，所以这是最值得试的一类外部资源。

**外部资源**：1011 Yeast Genomes Project 的 SNP 距离矩阵
（Peter et al., *Nature* 2018；文件、日期、SHA-256 见依赖披露）。

**做法只改编码、不改模型**：把未见菌株写成训练菌株的凸组合，
权重 `w(s*,s) = exp(−(d/h)²)` 归一化后整体乘收缩系数 γ。
容量锁死在两个标量——合法训练菌株只有 4 株，其中只有 3 株能在面板里按代号命中，
再多的基因组特征也没有可拟合的自由度。

**四个方案同时跑，缺一个结论就不成立**：

| 方案 | 它排除什么 |
|---|---|
| `zero`（未见菌株整块 0） | 现状，作基准 |
| `uniform`（有坐标的训练菌株等权） | 排除「把 0 换成平均值」本身的收益——这部分与基因组无关 |
| `snp`（距离核加权） | 真正要检验的东西 |
| `null`（换成面板里随机一株的距离行） | 排除「随便哪一株的坐标都行」 |

**结果**：train 内留一菌株的网格里，**每一个 γ>0 的配置都比现状差，且随 γ 单调变差**；
SNP 加权相对等权的增量是 **+0.0000**。

官方 `val_strain_only` 一次性验证，对照预先写死的判据：

| 判据 | 要求 | 实测 |
|---|---|---|
| drug_resid 增量 | ≥ +0.015 | **−0.0010** |
| 六项总分增量 | ≥ +0.003 | **−0.0008** |
| abs_r2 变化 | ≥ −0.005 | −0.0014 |
| S1 abs_r2 变化 | ≥ −0.005 | +0.0000 |

**裁决：不保留，永久停止该路线。**

两点值得记下来：

1. 它**反过来支持了现有架构**：C-free 骨架对未见水平的处理（整块归零、回退总体先验）
   不只是省事的默认值，在本数据上就是最优的那一档。
2. **可验证性是不对称的，必须说清楚**：未见菌株与某训练菌株的 SNP 距离 0.398
   （面板分位 14.6%，三个供体的距离跨度 1.70）——加权在这一格差别极大，
   却**无法验证**；唯一能验证的那一株到三个供体近乎等距（1.362，分位 73.8%，跨度 0.41）——
   **验不出加权**。所以本节能支持的结论只到「搬运机制在本数据上不带来增益」，
   **不能**反过来说「菌株基因组对该任务无用」。

### 6.2 结构性发现：测试集的对照结构与训练集根本不同

这一段比总分更值得看。

| 场景 | 处理样本 | 有匹配对照 | 覆盖率 |
|---|---|---|---|
| `test_chem_only` | 1,640 | 52 | **3.2%** |

| `test_time` | 135 | 8 | 5.9% |

根因：test 全表只有 **202 行**溶剂对照，其中 **188 行属于未见菌株那一株**。

为什么要紧：`Δ_true = 处理 − 匹配对照`。没有匹配对照的样本，Δ 整行无定义，
于是**指标 2/3/4/5/6 全都算不到它头上**——那是 80% 的权重。
train_val 上 0 匹配率是 0.0%，test 上过半，**两边的评估基础不同**。

实际后果有三条：

1. test 上的 Δ 类指标由**未见菌株那一格主导**——S2 的实际分量比 50.1% 的行占比还重；
2. 指标 3（上下文残差）在 test 上只落在很薄的一层样本上，其读数的不确定性远大于 val；
3. **val 与 test 的读数不可直接互推**，两张表要分开看。

⚠ 这条**不构成**照着 test 调模型的理由。手册明说 test 不作排名依据，
最终评审用另一组数据。它的用途只有一个：让评审和我们自己都知道，
这些数字各自建立在什么样的样本基础上。

## 七、合规整改与它值多少分

复赛门槛是「晋级队伍须通过代码复现核验，核查不通过者不计成绩」。
本轮修掉两处训练边界违规，并把结论重做在合法样本上。

### 7.1 修了什么

手册第 17 页：训练仅可使用 train 划分的蛋白质组标签，
**验证集与测试集均不得参与训练，也不得用于估计任何统计量**（含保留蛋白列表与归一化参数）。

- **统计量泄漏**：设计矩阵的类别词表与 log-time 标准化参数在整张表上估计。
  改法是**删掉违规函数本身**，全部改走 freeze/encode 分离的新实现——
  词表与标准化参数只由拟合行冻结。留着开关就等于留着违规路径。
- **拟合行泄漏**：提交脚本有 `--fit-rows {train,all}` 且默认 `all`。
  删的是**选项本身**。因此保留蛋白列表与时间标准化参数现在也只由 train 折估计。
- **科学证据违规**：LOCO 外层留出宇宙取自全 train_val，当折未被留出的 val 化合物
  照样进了训练。现在收进 train 折的 37 个化合物重跑。

### 7.2 合规不是声明，是可运行的检验

`python scripts/audit/train_boundary_probe.py`：

**静态扫描**挡三类已踩过的写法。扫描器自己先过阳性对照（三类违规全中）
与阴性对照（只在文字里谈论违规的干净文件零命中）——第一版正是栽在阴性对照上，
把文档字符串里讲规则的话当成了违规代码。

**经验探针**：把 `split_final != 'train'` 的每一行都破坏掉（丰度换随机数、
缺失掩码重画、类别字段换假水平、时间换乱数），从头再拟合一次。
若模型真的只由 train 折决定，冻结的设计 spec、`mu`/`U`/`W`、保留蛋白列表，
以及最终交出去的 4,454 × 5,243 预测矩阵，**必须逐位相同**。

实测：破坏 **13,798,081** 个单元格，上述全部**逐位相同**；
而同一破坏下的 val 总分从 0.4694 掉到 −0.6670——证明破坏确实生效，不是没改到。

### 7.3 两处违规各值多少分（分开讲，量级差很远）

`scripts/audit/quantify_l1_leak.py` 把旧写法原样复刻，与合规写法在同一批数据上对打：

**统计量泄漏**：低秩总分差 **+0.000000**，满秩 **−0.000000**，
两种写法的预测矩阵逐元素差中位 0、最大 `1.3e-5`。

为什么差这么小，必须解释清楚，否则读者会以为在敷衍：

1. val 独有的那个菌株水平在 train 行上整列为 0，岭回归给它的系数**恰好是 0**——
   多出来的那一列是空转的；
2. log-time 三次多项式 `{u, u², u³}` 在有截距的情况下，与换标准化参数前
   张成**同一个列空间**，改的只是同一空间内的重参数化。

→ 这一处是**程序性**违规，成绩没有被它抬高。但它必须修：
复现核验查的是代码里有没有这条路径，而且换一套数据（比如 val 独有水平在 train 里
也出现过部分行）它就会真的影响结果。

**拟合行泄漏**：这一处真的改变了交出去的东西。

| 配置 | 拟合行 | 无观测蛋白列 | val total |
|---|---|---|---|
| 旧 · 全部 train_val | 8,958 | 186 | 0.502948 |
| 新 · 只用 train 折 | 5,920 | 189 | 0.469388 |

⚠ 旧那一行的 0.5029 **不是样本外分数**——val 行参与了它自己的拟合。
它看起来像 +0.033 的提升，实际是 val 标签泄进了自己的评估。两个数不可直接比大小。

test 预测的实际差异：逐元素绝对差中位 0.0357、均值 0.0713、p99 0.5584、最大 5.1491，
整体相关 0.998401。保留蛋白列表也从 186 变成 189——那正是手册点名的两类统计量之一。

## 八、三道数字防线

数字靠手抄进文档，源头一改抄件不会跟着改。这类漂移我们踩过——
共享参照那组数在两份文档里出现过两个版本。所以设了三道：

| 防线 | 脚本 | 管什么 |
|---|---|---|
| 一 | `authoritative_results.py` | 定义哪个数是对的，现场重算，文档只许引用 |
| 二 | `stale_number_scan.py` | 查已作废的数是否还在流通 |
| 三 | `doc_number_check.py` | 反向扫描：文档里的数是否都能追到出处 |

第三道是 2026-08-07 改成反向的。改之前只做正向核对——遍历权威表看每项是否出现在
文档里，文档中多出来的数它一个都看不见，而且失败计数恒为 0，**永远不会失败**。

本轮新登记 3 个作废值（LOCO 违规版留下的），并把已提交的初赛定稿整体标为存档
——那份稿子的内容一字不改，但它的数字不得再被引用。

⚠ 有一类数防不住，得说明白：LOCO 的 Morgan 增益旧值 −0.0004、新值 +0.0004，
数字串完全相同，只有符号不同。把它登记成作废值会连**现行的正确值**一起判错，
所以第二道防线对这类同串异号的数无能为力，只能靠第三道的正向核对兜住。

## 九、已知局限

按影响从大到小：

1. **分组 bootstrap 只有 60 次**，应提到 500–1000 次。当前区间是保守读数，
   但精度不足以支撑更细的模型比较。
2. **测试集对照覆盖率的成因未知**。我们只观察到 test 的溶剂对照高度集中于未见菌株，
   没有证据说明这是设计还是数据发放的产物，因此不据此做任何建模调整。
3. **`protein_well`（制备孔位）尚未接进模型**。响应空间里它的残留 η² = 0.272，
   但 η² 不等于预测增益，这只是一个**候选假设**，不是确定增量。
4. **化合物计数有四个口径**（官方 56 / 我方非对照 43 / train 折 37 / test 非对照 54），
   引用时必须说清用的是哪一个。权威表的 `entity_census` 一次算清。
5. **菌株基因组路线的否定有边界**，见 5.2 第 2 点：能验证的那一格验不出加权，
   最需要加权的那一格验不了。
6. **未见菌株那一株的生物学身份未落实**。代号能在 1011 面板里命中，
   但产地、生态位、倍性等未逐个取证——未做即不声称。
