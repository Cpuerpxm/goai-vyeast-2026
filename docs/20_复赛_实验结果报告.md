## 摘要

可提交模型是一条 C-free 骨架：仅以元数据为输入，推断时不读取该样本的实测对照。
模型是满秩逐蛋白掩码岭回归，设计矩阵分四类结构块（测量上下文、培养板号、
药物与其时间轨迹、菌株与上下文的交互），未见药物另由分子结构迁移补一份响应，
输出 4,422 维标准建模空间的 log2 丰度。官方四类 val 六项加权总分 **0.5610**，
高于全部需读对照的 oracle 诊断基线（最高 0.4126）。

> 架构沿革：2026-09-03 之前提交的是 `metadata → 低秩 K₀=16 → 全维解码`，总分 0.5008。
> 当天做了六轮消融，逐项证据见 §十二，最大的一笔来自把培养板号接进设计矩阵。
> 本报告 §四、§五、§六的实验记录仍是当时那条线上的，未改；
> §十二给出新架构的完整分块、λ 与逐 split。

本工作的重心在确立结论的可验证性：

1. 纠正了两处训练边界问题，并将合规性做成可运行的检验；
2. 在合法样本上重做了化合物结构表示的否定结论，并补充第二个阳性对照以排除模块失活的解释；
3. 按运行前固定的判据完成并否定了外部菌株基因组路线；
4. 首次做测试集真值自评，发现测试集的对照结构与训练集存在根本差异，直接影响对成绩的解读。

## 一、任务与评分口径

### 1.1 任务

给定酿酒酵母在特定菌株、化合物、培养基、温度、时间与测量上下文下的扰动蛋白质组，
预测独立测试样本的完整 5,243 维 log2 蛋白丰度向量。

四类外推场景：S1 未见化合物（`chem_only`）· S2 未见菌株（`strain_only`）·
S3 双重未知（`both`）· 时间插值（`time`）。

### 1.2 评分器实现：手册定死的照做，未定义的显式取值

**指标 1 沿样本轴计算，不附加蛋白轴分量。** 手册第 17 页对这一项给了定义：

> 绝对保真度（全蛋白质组真实性）| 20% | 适用全部划分。
> **逐样本 corr / R²（每个样本的预测向量对真值向量）**

既然写明了「逐样本」，就不能再套用为指标 2/3/4/6 准备的两轴平均规则——
那等于给一个已定死的口径自行添加分量。这一点对退化模型影响极大：
全局均值谱在每个蛋白上恒为常数，蛋白轴必然未定义，若按两轴平均并把未定义记 0，
逐样本的 0.9535 会被机械减半成 0.4768。指标 5 里以绝对保真度为主的那个分量同轴。

该口径由一个判别性单测锁住（`scripts/scorer/test_metrics.py`）：
fixture 刻意让样本轴（0.9997）与蛋白轴（−0.0055）差得极远，
实现若退回两轴平均会立刻被测出。

**手册未定义、需要我们取值的五处**（全部做成参数而非写死，
配 65 项单元测试）：

| 未定义项 | 我们取值 | 为什么这么选 |
|---|---|---|
| 多个合法对照如何合并 | 逐蛋白中位数 | 92.9% 的处理样本匹配到多个对照（中位 2 个），均值对离群对照不稳 |
| 常数向量导致 PCC 未定义 | 记 NaN | 见下条，与轴规则配合 |
| **指标 2/3/4/6** 沿哪条轴聚合 | 两轴等权平均；整条轴未定义时记 0 | 手册对这四项只写「计算 PCC(…)」，未指定轴。记「踢出」会奖励「让整条轴未定义」的退化模型 |
| 某个评分模块整体未定义 | 按 0 计入，分母保持满权重 | 同理，否则 Δ≡0 这类基线靠未定义指标虚高 |
| 指标 5 的构成 | FC 与绝对保真度都算 | 手册原文两个分量都提了，只算 FC 会漏掉一半 |

这套测试还锁住了一处容易被忽略的数值细节：

- **常数判据的阈值必须按浮点精度定，不能用绝对小量**：B2 的上下文残差理论恒为 0，
  阈值取 `1e-12` 时算出 0.0011，取合适阈值后为 0.0000。原因是预测按 float32 落盘时
  `(C + μ) − C` 会残留约 `2.4e-6` 的舍入噪声。现按 float32 在 log2 丰度量级上的
  表示精度取阈值 `1e-5`，Δ 的真实尺度 sd ≈ 0.4 比它大四个数量级，不会误伤。

## 二、数据实况

### 2.1 规模与缺失

| 项 | 值 |
|---|---|
| train_val 样本 / test 样本 | 8,958 / 4,454 |
| 蛋白维度 | 5,243 |
| 处理样本（非对照非质控） | 7,884 |
| 丰度缺失率 | 27.35% |
| 处理样本的 Δ 缺失率 | 28.93% |
| 全缺失蛋白列 | 丰度侧 186 · Δ 侧 213 |

缺失**不是随机的**：蛋白中位丰度与其缺失率的 Spearman 相关 **−0.859**；
最低丰度十分位的缺失率 **77.4%**，最高十分位 **1.6%**。
这是典型的检测限截断（MNAR）。**缺失位置不作为已观测目标、不进损失项**，
也不当作已知值参与任何统计量的估计。

⚠ 需要说清楚的边界：缺失位置在目标函数中的观测权重为 0，但掩码 EM-PCA 在迭代
内部会用当前重建值临时填上再做一次 SVD——那是加权最小二乘的等价实现。
这些临时值不被当作观测数据，不进损失、不落盘、不参与参数估计。

### 2.2 对照匹配

按手册规定的 7 项键（来源/菌株/培养基/温度/时间/仪器/板号，不含孔位）匹配：

- train_val 侧 **0 匹配率 0.0%**，多匹配比例 92.9%（中位 2 个对照）
- test 侧的情况完全不同，见第六节

### 2.3 生物与技术因素高度混杂

板号与培养基 / 温度 / 时间的 Cramér's V 全部是 **0.992**。
生物 + 技术的联合设计矩阵 296 列、秩 267，**亏秩 29**。

因此板号不作为预测特征。加入板号等于将培养基、温度与时间的身份直接记忆，
换一批新板即失效。亏秩 29 说明这几列在训练集上已不可辨识；
更关键的限制在部署端——新板是训练时不存在的水平，对应系数无处可用。

### 2.4 单样本 Δ 的可靠性只有 0.115

跨板 / 跨来源的复制对共 4,384 对，逐样本相关：

| 空间 | ρ |
|---|---|
| 绝对 log2 丰度 | **0.921** |
| Δ_true（匹配 FC） | **0.115** |
| Δ − μ_ctx | 0.157 |
| Δ − μ_drug | 0.059 |

⚠ 这个 ρ 是**操作性一致性**，不应解释成「信号只占 11.5%」——
它同时包含了对照匹配引入的方差。

方向是明确的：**在这个口径下，绝对丰度的跨批次一致性高，单样本响应的很低**。
这一条直接决定了架构优先级——优先建准绝对基线，而非为每个化合物学习一条响应谱。

## 三、共享参照效应：零知识模型也能在扰动指标上得分

评分定义里 `Δ_pred = ŷ − y_control` 与 `Δ_true = y − y_control` **减去同一条实测对照**。
于是一个对药物一无所知的模型，也能在扰动指标上拿到不低的分。

拿全局均值谱（B0，完全不含药物信息）做三条件对照实验：

| 条件 | 样本轴 PCC | 蛋白轴 PCC |
|---|---|---|
| 正确匹配（官方口径） | 0.1845 | 0.1898 |
| 错配到**同条件**的别的样本 | 0.0825 | 0.0855 |
| 全局错配到随机样本 | 0.0076 | 0.0038 |

一个完全不含药物信息的模型在指标 2 上得到 0.18。

⚠ 三条件之差**不能**拆成可相加的信号份额——相关系数不具可加性。
这组数只说明一件事：**共享参照抬高了零知识基线，指标 2 不可单独作模型选择依据**。

可复现实验：`scripts/audit/shared_reference_probe.py`。

## 四、模型与结果

### 4.1 为什么是 C-free

此前的 B1/B2/B3/B4、低秩响应、α 收缩**全部**是 `ŷ = C + Δ̂` 形态，
推断时需要读该样本自己的实测对照。

原来我们给的理由是保守假设（测试集真值被隔离）。
手册 2026-08 修订版推翻了那个前提——测试真值随包发布，供自评参考。
**但同一份手册第 17 页写着，最终评审用组委会另备的一组独立内部评测集，不随赛题发放。**

因此约束更为根本：**任何在推断时需要读该样本对照的模型，在那组不随赛题发放的
数据上无法运行。** 这是可用性约束，而非保守假设。

模型里有一道守卫强制这件事（`assert_c_free`）：判据是「预测与该样本自己的对照的相关，
不应高于它与**在模型所用条件变量上完全相同**的另一个样本的对照的相关」。
守卫自己先过阳性对照——拿一个已知偷用了 C 的模型（`ŷ = C`）去测，必须被拦下。
只有在能检出已知泄漏之后，该守卫给出的阴性结果才有解释力。

### 4.2 成绩

官方四类 val，六项加权总分：

| 组 | 模型 | total |
|---|---|---|
| 需读对照（oracle 诊断，**不可提交**） | B1 预测=匹配对照 | 0.3122 |
| | B3 化学近邻响应 | 0.3208 |
| | B2g 总体平均响应 | 0.3373 |
| | B2 上下文均值响应 | 0.3393 |
| | B3o 神谕近邻（目标派生参考） | 0.3518 |
| | B4 ridge 响应 | 0.3682 |
| | 对照收缩 α=0.15 | **0.4126** |
| C-free（**可提交**） | 全局均值谱 | 0.3770 |
| | 逐蛋白 ridge（满秩） | 0.4817 |
| | 低秩 K₀=16 + ridge（2026-09-03 前的提交模型） | 0.5008 |
| | **当前提交模型（见 §十二）** | **0.5610** |

⚠ 全表按 §1.2 的指标 1 口径（逐样本）统一计算。这个口径对退化模型影响最大——
全局均值谱在蛋白轴上恒为常数，若误用两轴平均会被机械减半。
口径不影响模型之间的排序，K₀=16 在两种算法下都是最优。

**不读对照的可提交模型，反而高于全部需读对照的诊断基线。**

⚠ 两组的推断前提不同，不是同一张名次表。上组只用来定水位。

### 4.3 低秩这一步值多少，以及怎么确认它不是噪声

> 本节是 2026-09-03 之前的记录。当时的满秩实现有一处缺陷（所有蛋白共用一个
> Gram 矩阵，缺失行没进 Z'y 却仍进了 G），低秩管线的岭回归作用在稠密的 PCA 系数上，
> 天然避开了它。缺陷修好之后满秩反超低秩 +0.0062，见 §12.1。
> 下面这个 +0.0185 的配对结论在当时的两个实现之间成立，不作为「低秩优于满秩」的一般结论。

从满秩逐蛋白 ridge 换成 K₀=16 低秩：总分 0.4817 → 0.5008。

**按化合物分组的配对 bootstrap**（**500 次**，46 个分组）：
差值均值 **+0.0185**，95% 区间 **[+0.0103, +0.0222]**，排除 0，低秩更优的比例 100%。

⚠ 采用 500 次重抽样以稳定 2.5% / 97.5% 分位估计。
分位数在尾部最不稳，低次数只够支撑「差值明显为正」这类方向性判断。

⚠ 判据必须看**配对差值**的区间，不能比较两条边际区间是否重叠——
两个模型跑在同一批数据与同一批重抽样上，估计高度相关。

⚠ 按行 bootstrap 会严重低估不确定性（同一化合物有上百个相关样本），故按整组重抽样。

### 4.4 K₀ 必须用端到端口径选

| K₀ | total |
|---|---|
| 8 | 0.4856 |
| **16** | **0.5008** |
| 32 | 0.5005 |
| 96（重建口径选出的） | 0.4992 |
| 满秩 | 0.4817 |

此前用「观察留出样本一半蛋白、重建另一半」选 K，选出 96。那是**插补**口径——
真实预测时看不到留出样本的任何蛋白值。两个口径选出的 K 不同，

## 五、两条被否定的路线

负结果同样是结果。两条路线都**先写判据、再跑实验**，不是跑完再找说法。

⚠ 用词说明：本文**不使用「预注册」**这个词。判据确实写在运行之前（阈值是脚本里的
常量），但判据与首批结果落在同一个提交里，**没有独立于结果的时间戳**。
在产学研评审的通常理解里，预注册意味着结果出现前存在不可回改的记录；
我们拿不出那样的证据，因此只声称「运行前固定的判据」，不声称预注册。

### 5.1 化合物结构表示：拿不到可验证的预测增益

严格 nested LOCO，取样范围收进 `split_final == 'train'` 的 **37 个**合法训练化合物，
8 折整化合物留出，化合物等权，指纹 bit 过滤与描述符标准化只在外层训练折内拟合，
λ 由内层二次留出选，每折的设计矩阵词表与时间标准化参数只由该折训练行冻结。

| 配置 | fc_pcc | 相对仅上下文 |
|---|---|---|
| 仅上下文 b̂（无化合物信息） | 0.3521 | — |
| + ECFP 结构表示 | 0.3526 | **+0.0004** |
| shuffled-label 对照（5 次） | — | −0.0000 ~ **+0.0007** |
| [阳性对照 2] 神谕特征**走同一模块** | 0.3739 | **+0.0217** |
| [阳性对照 1] 神谕挑近邻照搬残差 | 0.3822 | **+0.0300** |
| [参考] 神谕用留出化合物自己的平均残差（目标派生，**非上界**） | 0.4195 | **+0.0674** |

真增益 +0.0004 落在打乱对照的带子里（最大 +0.0007），与随机指派分不开。
按运行前固定的标准，结构项权重设为 0。

**这个否定为什么有效力——靠的是两个分工不同的阳性对照。**

- 对照 1（+0.0300）**绕过**岭回归模块，证明「b̂ + 化合物残差」这个架构能给分、
  评分口径也认。
- 对照 2（+0.0217）**不绕过**，走同一条 `fit_response`、同一套内层 λ 选择，
  只是把特征换成已知有信息的那种。它排除的质疑是：
  「你的模块是不是被内层 λ 压成 0 了？那 ECFP 拿不到增益是必然的，
  你这检验对『结构表示行不行』根本没有效力。」
  同一条路径换个特征就拿得到 +0.0217，**模块没有被正则压成 0**。

⚠ 对照 2 能排除的只有这一条。神谕特征是目标派生、与响应对齐、
低维且高信噪比的表示，在维数、几何、正则作用与样本效率上都与 ECFP 不同，
因此**不能**由它推出「ECFP 的失败确实就是表示内容的问题」。
它排除的是**「模块完全失活」这一狭义解释**，
而 ECFP 为何拿不到增益，仍有表示内容之外的多种可能（见下条 ⚠）。

官方 `val_chem_only` 一次性确认（6 个化合物，只看一眼、不参与选参）：
总分差 +0.0002，方向一致。

⚠ **可判定的只有**：当前的 2D 指纹与最近邻基线，不足以定位响应相似的化合物。
**不可升级成**「分子结构预测不了响应」——失效原因至少还有：只有 37 个合法训练化合物、
化学空间稀疏、只用 2D 指纹、作用浓度、摄取与外排、代谢、酵母中不存在的靶点、多靶点。

**一个目标派生的诊断参照**：用留出化合物自己的平均残差当 Δ̂。它用到了留出标签、
不可实现，只用来估计化合物特异信号的量级。fc_pcc 增益 +0.0674，
按指标 2 的 25% 权重局部折算约 +0.0168。

⚠ **它不构成上界。** 算术均值只对**平方误差**最优，不是平均 Pearson 相关的
最大化解。两维反例：正交基下同一化合物的两条响应为 (10, 0) 与 (0, 1)，
自身均值模板的平均 PCC 是 11/(2√101) ≈ 0.547，而固定模板 (1,1)/√2
拿到 1/√2 ≈ 0.707，更高。所以它连「固定单谱模型在样本轴平均 PCC 下的上界」
都不是，更不是全评分体系或所有化合物特异模型的上界。

⚠ 那个 +0.0168 的折算同样只是量级参照：它假设其余五项不受影响，未经检验，
既不是总分估计，也不是任何上界。

**能说的只到这里**：在当前评分器下，一个用留出真值构造出来的固定模板拿到 +0.0674，
而实际可实现的 ECFP 拿到 +0.0004（落在打乱带内）。这个对比说明当前表示与
「拿到真值再构造模板」之间还有距离，**不说明那个距离就是这条路线的全部空间**。

对比另一头：绝对骨架改一步（满秩 → 低秩）是 +0.0185，且 500 次配对区间排除 0。
两者不是同一口径（前者 fc_pcc 单模块，后者六项总分），不可直接比大小；
我们据此把力气放在绝对基线，是一个**工程取舍**，不是由上界推出的必然结论。

### 5.2 外部菌株基因组：按运行前固定的判据不保留

手册修订对照表允许外部公开资源用于实体特征构建。S2 是最弱的一格，
测试集里未见菌株占 50.1%，所以这是最值得试的一类外部资源。

**外部资源**：1011 Yeast Genomes Project 的 SNP 距离矩阵
（Peter et al., *Nature* 2018；文件、日期、SHA-256 见依赖披露）。

**做法只改编码、不改模型**：把未见菌株写成训练菌株的凸组合，
权重 `w(s*,s) = exp(−(d/h)²)` 归一化后整体乘收缩系数 γ。
容量锁死在两个标量——合法训练菌株只有 4 株，其中只有 3 株能在面板里按代号命中，
再多的基因组特征也没有可拟合的自由度。

⚠ 第 4 株没能命中的原因与后续处理，必须写清楚。它是实验室菌株命名，
不属于 1011 面板收录的野生与驯化分离株。组委会 2026-08-12 的通知里给了一条建议：
该株「可使用 SGD 的 S288C 参考基因组作为代理」。我们**没有照做**，理由如下：

S288C 在这套数据里是**比对参考**，不是那 1,011 株中的一员——面板由 918 个三字母
编号的分离株加 93 个此前已测序的 `SACE_*` 条目构成（本机对距离矩阵表头清点核实），
与原文「918 株深度测序 + 93 株此前已测序，reads 比对到 S288C 参考基因组」一致。
因此那条建议不是一次查表就能落实的：本方法工作在面板**预先算好的** SNP 距离空间里，
把 S288C 放进这个空间需要从群体级 gVCF 反推它到每一株的距离，是另一件工程。

**为什么判断这不改变结论**：唯一能验证的那一格里，SNP 加权相对等权的增量是
**+0.0000**（见下表）。也就是说在可验证范围内，基因组加权没有携带任何信息；
补上第 4 个供体会同时改变等权基线本身，不构成把 −0.0010 抬到那条固定阈值 +0.015 的
机制。**这是一条有界的说明，不是「基因组信息无用」的结论**——后者本节末已明确否认。

**四个方案同时跑，缺一个结论就不成立**：

| 方案 | 它排除什么 |
|---|---|
| `zero`（未见菌株整块 0） | 现状，作基准 |
| `uniform`（有坐标的训练菌株等权） | 排除「把 0 换成平均值」本身的收益——这部分与基因组无关 |
| `snp`（距离核加权） | 真正要检验的东西 |
| `null`（换成面板里随机一株的距离行） | 排除「随便哪一株的坐标都行」 |

**结果**：train 内留一菌株的网格里，**每一个 γ>0 的配置都比现状差，且随 γ 单调变差**；
SNP 加权相对等权的增量是 **+0.0000**。

官方 `val_strain_only` 一次性验证，对照预先写死的判据：

| 判据 | 要求 | 实测 |
|---|---|---|
| drug_resid 增量 | ≥ +0.015 | **−0.0010** |
| 六项总分增量 | ≥ +0.003 | **−0.0008** |
| abs_r2 变化 | ≥ −0.005 | −0.0014 |
| S1 abs_r2 变化 | ≥ −0.005 | +0.0000 |

**裁决：不保留，永久停止该路线。**

两点值得记下来：

1. 它**反过来支持了现有架构**：C-free 骨架对未见水平的处理（整块归零、回退总体先验）
   不只是省事的默认值：在我们测过的全部搬运方案与收缩系数上，它都是最好的一档。
2. **可验证性是不对称的，必须说清楚**：未见菌株与某训练菌株的 SNP 距离 0.398
   （面板分位 14.6%，三个供体的距离跨度 1.70）——加权在这一格差别极大，
   却**无法验证**；唯一能验证的那一株到三个供体近乎等距（1.362，分位 73.8%，跨度 0.41）——
   **验不出加权**。所以本节能支持的结论只到「搬运机制在本数据上不带来增益」，
   **不能**反过来说「菌株基因组对该任务无用」。

### 6.2 测试集的对照结构与训练集存在根本差异



| 场景 | 处理样本 | 有匹配对照 | 覆盖率 |
|---|---|---|---|
| `test_chem_only` | 1,640 | 52 | **3.2%** |
| `test_strain_only` | 1,322 | 1,322 | **100%** |
| `test_both` | 1,129 | 697 | 61.7% |
| `test_time` | 135 | 8 | 5.9% |

根因：test 全表只有 **202 行**溶剂对照，其中 **188 行属于未见菌株那一株**。

为什么要紧：`Δ_true = 处理 − 匹配对照`。没有匹配对照的样本，Δ 整行无定义，
依赖 Δ 的指标（2、3、4、6，以及指标 5 里的 FC 分量）在这些样本上算不出来。
train_val 上 0 匹配率是 0.0%，test 上过半，**两边的评估基础不同**。

⚠ 这里有两处容易概括过头，需要说准：

- **不是「五项全废」**。指标 1 只需要绝对丰度，与对照无关，照常计算；
  指标 5 里的「绝对保真度」分量同样不受影响。受影响的是 Δ 类的那部分。
- **不是「五项都被未见菌株主导」**。各指标的样本来源本就不同：
  指标 3 只取 `chem_only`，指标 4 只取 `strain_only`，指标 5 只取 `both` 与 `time`。
  准确的说法是：在**可算 Δ 的 2,079 个处理行**里，`test_strain_only` 占 **63.6%**，
  所以覆盖全部处理行的指标 2 与 6，其样本基础以未见菌株那一格为主；
  而指标 4 本来就全部来自它。

剩下两条后果是站得住的：

1. 指标 3（上下文残差）在 test 上只落在 52 个样本上，其读数的抽样方差预期远大于 val；
2. **val 与 test 的读数不可直接互推**，两张表要分开看。

⚠ 测试集真值仅供自评参考，不作排名依据，不据此调整建模选择。
上述分析旨在说明各指标读数所依赖的样本基础。

## 七、训练边界合规

手册第 17 页要求训练仅使用 train 划分的蛋白质组标签，验证集与测试集不得参与训练，
也不得用于估计任何统计量。本方案的合规性通过以下设计保证，并有可运行的检验。

### 7.1 实现方式

设计矩阵的构建分为冻结与编码两步（`freeze` / `encode`）。词表、log-time 标准化参数、
保留蛋白列表均在 `freeze` 阶段由 train 折的 5,920 行冻结，编码阶段只做查表。
未见水平整块归零。LOCO 验证的取样范围限定在 train 折的 37 个化合物内。

### 7.2 合规检验

`python scripts/audit/train_boundary_probe.py` 提供两层检验：

**静态扫描**：检查三类可能导致非 train 统计量进入模型的代码模式。
扫描器本身通过阳性对照（构造的违规样例全部命中）与阴性对照（纯文字描述零命中）
验证其检出能力与误报控制。

**经验探针**：将 `split_final != 'train'` 的每一行破坏（丰度换随机数、缺失掩码重画、
类别字段换假水平、时间换乱数），从头重新拟合。若模型仅由 train 折决定，
冻结的设计规格、模型参数与最终 4,454 × 5,243 预测矩阵必须逐位相同。

实测结果（2026-09-03 在当前提交模型上重跑）：破坏 **12,477,690** 个单元格后，
设计 spec、mu、W、保留蛋白列表与 4,454×4,422 预测矩阵**全部逐位相同**；
同一破坏下 val 总分从 **0.5610 变为 −0.6662**，确认破坏生效。

test 元数据探针同样 PASS：把 `metadata_test` 的类别字段换成假水平、时间换成乱数，
冻结的 spec 与 mu / W 逐位不变，而 test 预测跟着变了——
这正是「只用 train 折估计、对 test 只做编码」应有的样子。

> 单元格数从旧版的 13,798,081 降到 12,477,690，是因为建模空间从 5,243 列
> 收到官方规定的 4,422 列，被破坏的行数不变（3,038 行）。

### 7.3 代码与结果的对应

本文全部数字由 `scripts/scorer/authoritative_results.py` 现场重算。
代码身份通过 `tree_digest`（`scripts/` 下全部 `.py` 的 SHA-256 汇总）锁定，
公开仓库 tag 与 commit 记录在 `RELEASE.json` 中，两者均可独立复算。

⚠ 一处需要说明的地方：发布是两次提交完成的——先推代码与材料，再重跑权威表把 tag
写进表里推第二次。所以 `RELEASE.json` 里的 `commit` 记的是**第一次**那个提交，
而 tag 指向**第二次**。两次之间 `scripts/` 一个字节没变，`tree_digest` 相同，
代码身份不受影响；这样安排是为了让 clone 该 tag 的人拿到的权威表已经填好 tag。

**独立复算核验**：另起干净目录，用 Windows 默认的 `core.autocrlf=true` clone tag
`semifinal-v8`，按同一规则重算得 `d471a07afef25586`，与权威表登记的一致。
特意用 `true`，因为那正是原本会算错的那种环境——
`provenance` 在哈希前把 CRLF 归一成 LF，仓库根的 `.gitattributes` 从另一头兜住。

## 十二、2026-09-03 的架构更替

摘要里那条 `metadata → 低秩 K₀=16 → 全维解码` 是本报告 §四到 §六记录的模型，总分 0.5008。
外部会诊指出岭回归实现有一处缺陷之后，当天做了六轮消融，架构换成下面这条，总分 0.5610。
每一轮都在官方四类 val 上评，val 行全程没参与拟合，也没参与冻结任何统计量。

### 12.1 分数怎么走的

| 步 | 改动 | total | 增量 |
|---|---|---|---|
| 0 | 原提交模型（低秩 K₀=16，5,243 列） | 0.5008 | — |
| 1 | 切进 4,422 标准建模空间后重训 | 0.4998 | −0.0010 |
| 2 | 岭回归改逐蛋白 Gram | 0.5060 | +0.0062 |
| 3 | λ 从 30 细扫到 3 | 0.5069 | +0.0009 |
| 4 | 药物 one-hot + 分块正则 | 0.5099 | +0.0030 |
| 5 | **培养板号进设计矩阵** | 0.5446 | **+0.0347** |
| 6 | 药物 × 中心化 log 时间 | 0.5461 | +0.0015 |
| 7 | 四块 λ 粗网格（81 组合） | 0.5483 | +0.0022 |
| 8 | **菌株 × 来源 × 培养基（粗细两层）** | 0.5599 | **+0.0116** |
| 9 | 未见药物的分子结构迁移 | **0.5610** | +0.0011 |

第 2 步那个缺陷值得单列：原实现所有蛋白共用一个 Gram 矩阵 `G = Z'Z + λI`，
只在右端 `Z'y` 上按观测数重标定，缺失行虽然没进 `Z'y`，却仍然进了 `G`。
正确形式对每个蛋白只用它自己的观测行。合成数据上两种实现最大差 0.4401（相对 17.55%）。
修好之后满秩反超低秩 +0.0062，也就是说 §4.3 记录的低秩优势有一部分来自这个缺陷。

### 12.2 板号为什么是最大的一笔

手册第 17 页的对照匹配键有 7 项，**含板号、不含孔位**。处理样本与它的匹配对照
来自同一块板，所以板效应在 Δ_true = y_treat − y_ctrl 里正好抵消。
而原设计矩阵里没有板项，于是

    Δ_pred = ŷ − y_ctrl = base − (base_ctrl + plate + noise)

凭空多出一个 −plate。真值那边这一项是抵消的，预测这边却带着，这是系统性偏差。
加上板项就消掉了，六项一起上升。

孔位 `protein_well` 不在匹配键里，Δ_true 里本来就带着两个孔位之差，
所以它只能加信息、消不掉偏差。两个基线上各试一次，都是负的（§12.5）。

顺带查清一件结构性的事：板号 × 时间的水平数与板号相同（都是 144），
说明每块板只对应一个时间点，来源、培养基、温度、仪器同理。
所以 **7 项匹配键里板号一个变量就决定了 6 项**，唯一不被它决定的是菌株——
这也解释了为什么下一步的菌株交互同样值钱。

### 12.3 菌株 × 上下文交互

设计矩阵原本全是主效应，等于假设菌株的效应在每个来源、每种培养基下都一样。
逐个试「菌株 × 单个匹配键变量」（相对 0.5483 基线）：

| 交互项 | 水平数 | 最好 total |
|---|---|---|
| 菌株 × 温度 | 8 | 0.5481（负） |
| 菌株 × 时间 | 24 | 0.5490 |
| 菌株 × 培养基 | 8 | 0.5509 |
| 菌株 × 仪器 | 28 | 0.5540 |
| 菌株 × 来源 | 16 | 0.5564 |
| **菌株 × 来源 × 培养基** | **32** | **0.5589** |
| 菌株 × 来源 × 培养基 × 温度 | 64 | 0.5564（更差） |
| 菌株 × 来源 × 培养基 × 仪器 | 110 | 0.5554（更差） |

32 水平那档是顶，再往深走就掉。粗细两层同时进（32 水平 + 16 水平，各自的 λ）
比单独任一层都好，两层的 λ 起了分层收缩的作用。

理论终点是「菌株 × 板号」，即完整的 7 元组匹配组（383 组）。设计维会到 630，
逐蛋白 Gram 需要约 14 GB，本机放不下，故未做。

### 12.4 未见药物的结构迁移

test 里 2,769 行的药物在训练折没出现过，药物 one-hot 对它们整块是 0，
模型等于预测「这个药什么也没干」。这 2,769 行全部有 SMILES，val 那边 1,334 行也全部有。

不能直接把描述符当特征塞进设计矩阵：训练折只有 37 个有 SMILES 的药物，
药物 one-hot 正好 37 列，会把药物那层方差吃干净，描述符系数被压到 0。所以走两步：

1. 照常拟合，取出已见药物的效应矩阵 E（37 × 4,422），即 W 里药物那几行；
2. 在这 37 个点上做岭回归 E ~ D（D 是 20 维 rdkit 描述符，标准化参数只由训练折药物估）；
3. 未见药物用自己的描述符算 α·(d·C) 补进预测。

逐 split 是这一项最硬的证据：药物**已见**的三个划分逐位不变
（val_strain_only 0.390696、val_time 0.499949、train 0.542444，加与不加完全相同），
只有未见的两个上升（val_chem_only 0.4320 → 0.4347，val_both 0.3264 → 0.3284）。
干预精确落在它该落的行上。

与 §5 记录的 B3 化学近邻（0.3208，输给上下文均值基线 0.3393）的区别：
B3 是挑一个最相似的药把它的 Δ 整条搬过来；这里是把 37 个药一起回归出一张
结构到响应的映射，再对新分子求值。同一份 SMILES，两种用法，结论相反。

外部资源：`data/external/compound_smiles.csv`（PubChem 离线映射，已在依赖披露里）；
描述符由本机 rdkit 2024.09.5 现算，不联网。

### 12.5 试过但不采用的十一项

每项都设了实验前固定的止损线：相对基线涨 ≥ +0.0007，且 abs_r2 跌幅不超过 0.0015，
两个残差指标任一跌幅不超过 0.003。

| 试的东西 | 最好结果 vs 当时基线 |
|---|---|
| 孔位 `protein_well` 强收缩（无板号基线） | 0.5098 vs 0.5099 |
| 孔位（有板号基线上重测） | 0.5436 vs 0.5446 |
| 未见水平按训练频率软回退（菌株 / 药物） | 0.5100 vs 0.5099 |
| 满秩与低秩小比例混合 β ∈ [0.05, 0.5] | 0.5099 vs 0.5099 |
| 板号系数矩阵 SVD 降秩 r ∈ [5, 80] | 0.5304 vs 0.5446 |
| λ 按每蛋白观测数缩放 p ∈ {0.5, 1} | 0.5441 vs 0.5446 |
| 监督式降秩回归 RRR 硬截断 r ∈ [10, 200] | 0.5485 vs 0.5483 |
| RRR 连续谱收缩 | 0.5485 vs 0.5483 |
| 药物 × log时间² | 0.5483 vs 0.5483 |
| 菌株 × 温度 | 0.5481 vs 0.5483 |
| 菌株四阶交互（加温度或仪器） | 0.5564 / 0.5554 vs 0.5589 |

RRR 那两项值得说一句：拟合信号 Ŷ 的谱看着极度低秩（前 10 个方向解释 94.2%，
前 30 个 98.4%），但截到任何秩都不如满秩。板号系数矩阵同理，前 20 个奇异值
只解释 70.4%。**这份数据的结构本身就是高维的，「批次效应活在低维子空间」
这个常见假设在这里不成立。**

### 12.6 定稿配置与合规复核

设计 295 列：上下文 23 + 板号 144 + 药物 40 + 药物×时间 40 +
菌株×来源×培养基 32 + 菌株×来源 16。
λ 依次 3 / 10 / 100 / 30 / 100 / 300；结构迁移 λ_C=10、α=1。

λ(菌株×来源×培养基)=30 那档总分 0.5622，比定稿高 0.0012，但 drug_resid 掉 0.0056，
越过实验前定死的 −0.003 止损线，故不取。止损线是实验前定的，不因总分好看而放宽。

- 板号与来源、仪器都是手册明列的**测量上下文**，原文写明「测量上下文用于吸收
  测量过程引入的变异」；
- 拟合行仍然只有 `split_final=='train'` 的 5,920 行，`sg.assert_train_only`
  在每个函数入口强制；
- 覆盖率：板号在 val 与 test 上 100% 命中已见水平；菌株交互命中 40.2%
  （其余行整块归零，退回主效应）；结构迁移覆盖 test 2,769 行；
- C-free 守卫在含板号的条件集下通过：与自身对照相关 0.9940，
  与同条件他人对照相关 0.9941，差 −0.0001。

还有一条反向证据：若预测里混进了对照的值，Δ_pred 与 Δ_true 共享的 −C 项会被削弱，
相关应当下降。实测六项全部上升，方向与泄露相反。
